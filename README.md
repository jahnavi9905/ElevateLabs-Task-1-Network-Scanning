# 🔍 Network Scanning and Open Port Analysis

## 🎯 Objective

To identify open ports on devices within a local network, understand the services running on those ports, and assess potential security risks.

## 🛠️ Tools Used

- **Nmap** – Network scanning and port discovery
- **Wireshark** – Optional packet capture and traffic analysis
- **Windows 10** – Operating system used for the practical
- **Command Prompt / Terminal** – Used to execute scanning commands
